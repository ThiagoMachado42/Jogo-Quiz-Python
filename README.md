# Jogo Quiz em Python 🐍

Meu primeiro projeto em Python!

## Sobre o projeto

Um jogo de perguntas e respostas desenvolvido no terminal, no qual o jogador responde a perguntas sobre tecnologia e acumula pontos de acordo com seus acertos.

## Tecnologias utilizadas

- Python 3
- Estruturas condicionais (`if/else`)
- Manipulação de strings
- Entrada e saída de dados (`input` e `print`)

## Como executar

1. Tenha o Python 3 instalado.
2. Baixe este repositório.
3. Execute no terminal:

```bash
python JogoQuiz.py
```
